# தன்விவரங்கள்
[![தன்விவஙர்களின் சோதனைகள்](https://github.com/lassi-niruvanam/tanvivarangal/actions/workflows/சோதனைகள்.yml/badge.svg?branch=main)](https://github.com/lassi-niruvanam/tanvivarangal/actions/workflows/சோதனைகள்.yml)

`தன்விவரங்கள்` உங்கள் தன்விவரங்களைப் பல மொழிகளில் வெளியீடுகிறதற்கு ஒரு கருவி ஆகும்.

**இது செயற்கை நுண்ணறிவு கிடையாது! எல்லா மொழியாக்கங்கள் நீங்களே குறிப்பிடவும்.** தன்விவரங்கள்
உங்கள் சுயவிவரங்களில் உள்ள தகவல்கள் எடுத்து, மொழியாக்கப்பட வேண்டிய உரைகள் `.json` கோப்புகளில் எழுதும்.

அந்த மொழியாக்கங்களின் படியாக, வேண்டிய மொழிகளில் உங்கள் தகவல்களை வெளியிடும்.

## உபயோகம்
முதலில், `தன்விவரங்கள்` பொருள் உருவாக்கவும்.

```python
from தன்விவரங்கள்.உருப்படி.தேதி import தேதி
from தன்விவரங்கள்.தன்விவரங்கள் import தன்விவரங்கள்

நான் = தன்விவரங்கள்("த")

நான்.பெயர்("Julien Malard-Adam", "fr")
```

உங்களல் தொடர்புகளைச் சேகரிக்கலாம்.
```python
from தன்விவரங்கள்.உருப்படி.தொடர்புகள் import மின்னஞ்சல், இணையத்தளப்_பக்கம், தொடர்புகள்

# தொடர்பு
என்_மின்னஞ்சல் = மின்னஞ்சல்("julien.malard@mail.mcgill.ca", சின்னம்=None)
என்_இணையத்தளப்_பக்கம் = இணையத்தளப்_பக்கம்("https://cv.hal.science/julienmalard-adam")
என்_தொடர்புகள் = தொடர்புகள்([என்_மின்னஞ்சல், என்_இணையத்தளப்_பக்கம்])
நான்.உருப்படியைச்_சேர்(என்_தொடர்புகள்)

```

தெரிந்த மொழிகள்

```python
# தெரிந்த மொழிகள்
நான்.தலைப்பு("மொழிகள்")
நான்.மொழிகள்(
    நிலை="தொழில்முறையான அறிவு",
    தெரிந்த_மொழிகள்=["français", "हिंदी", "தமிழ்"]
)

```

ஆராய்ச்சியாளர்களின் வெளியீடுகளை ஸோதெரோ (Zotero) கோப்பிலிருந்து இறக்குமதி செய்யலாம்.
```python
நான்.வெளியீடுகள்("references.bib")
```

வேலை வரலாறு
```python
from தன்விவரங்கள்.உருப்படி.மேம்ப்பட்டவை.வேலை import வாழ்க்கைபோக்கு, வேலை

# வேலைகள்
நான்.தலைப்பு("வாழ்க்கைபோக்கு")

தற்காலிகமான_வேலை = வேலை(
    "ஆராய்ச்சியாளர்",
    நிறுவனம்="Institut français de Puducherry - IFP",
    இடம்="புதுச்சேரி, பாரதம்",
    தேதிகள்=தேதி(2025, 5)
)
வேலைகள் = வாழ்க்கைபோக்கு([தற்காலிகமான_வேலை])
நான்.உருப்படியைச்_சேர்(வேலைகள்)
```

இறுதியில், வேண்டிய மொழிகளில் உங்கள் தன்விவரங்களை வெளியிடுங்கள். 
```python
# நான்கு மொழிகளில் வேண்டும்
மொழிகள் = [
    "த", "fr", "हिं", "తె",
]

நான்.மொழிபெயர்ப்பு_கோப்புகளை_உருவாக்கு(மொழிகள்)
நான்.வெளியிடு(
    மொழிகள்,
    வடிவூட்டம்=["odt", "pdf"],
    கோப்புரை="தன்விவரங்கள்"
)
```
